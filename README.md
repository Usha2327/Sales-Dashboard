# Sales-Dashboard

A clean, interactive sales dashboard built using Tableau, visualizing Superstore sales performance by region, category, and month.
Tools (Tableau, Superstore Sales Data)

📈 Features
Line chart: Monthly sales trend
Bar chart: Sales by region
Donut chart: Sales by category
Region/category filters for interactivity

🔍 Key Insights
• The Central region had the highest total sales, outperforming other regions 
  significantly.
• Office Supplies was the top-performing category, generating slightly more revenue 
  than Furniture and Technology.
• Sales peaked in Month 8(August), reaching the highest monthly revenue of 
  approximately 1.14 million dollars.
